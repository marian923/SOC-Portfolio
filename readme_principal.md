# SOC Analyst Portfolio

## About Me

Junior SOC Analyst and Systems Engineer focused on Blue Team operations, incident investigation, threat detection, log analysis, and security monitoring.


This portfolio contains reconstructed investigations of real-world cybersecurity incidents based on publicly available information, technical reports, and the MITRE ATT&CK framework. Each investigation follows a structured incident analysis methodology and includes attack mapping, detection opportunities, and lessons learned.

In addition, this repository includes operational SOC playbooks designed to support analysts during common security incidents by providing standardized investigation and response procedures.
